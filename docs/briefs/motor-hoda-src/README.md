# موتور حودة (Hoda's Engine): low-poly cutscene source

A street episode with two new characters linked to the main cast:
- **Hoda**, the tuk-tuk driver whose engine Ibrahim used for the Jet Dishwasher 3000.
- **Uncle Sayed**, the building's sly doorman.

Hoda asks Sayed about the engine, and Sayed points him (for a tea tip) to the third-floor balcony. Ibrahim lowers the engine back down, now "upgraded"
with a nuclear booster, and the tuk-tuk launches into the sky. A "New vehicle unlocked: Tuk-Tuk 3000" showroom closes the episode.

- 54.5 s, 4:3, with no episode number.
- `scene6.js` is `engine6.js` (the shared engine, character rigs and Ibrahim) plus `ep6.js` (the street set, the tuk-tuk, Hoda, Sayed and the HUD).
- Voices: Google AI Studio, recorded by the Claude-in-Chrome extension as 3 multi-speaker runs. `lines.json` maps each line to its run and time range.
- `sfx6.py` is the synthesised score and SFX: street ambience, shaabi tabla groove, tea slurps, rope, engine rev, launch and showroom loop.
