# doc-toolkit: shared code for «حصلت إزاي؟» episodes. ep.js = common.js + cars.js + episode code. common.js: fixed lights + real sun shadows (enableShadows/aimShadow) + gradient sky, cast-style makePerson, overlay pop-ins (renderOverlay/placeInFront), subtitles, title/tags/CTA. cars.js: detailed cars v2 (extruded body, glass, lights, rims, plates, contact shadow), vans, trucks. Check new vehicles with projects/cartest (six angles) before using them.
